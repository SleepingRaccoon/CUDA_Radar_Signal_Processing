# 细节

我们用python进行仿真，内存布局行优先，每一个矩阵是

dr[Nd][Nr]，每一行是一个LFM

所有窗口遵循前闭后开原则，LFM的脉宽是Tp，采样率是fs，则采样点数是Ns = floor(Tp * fs)

接收窗口从[t_start, t_end), 一般来讲，t start至少是Tp，t_end至多是Tr（PRT，1/PRF），

这样接收窗口的点数Nw = floor（（t end - t start）* fs）

我们期望距离轴是c / 2 * t_start + delta r * j （j = 0， 1，.... Nr - 1）Nr是最终保留的距离点数

那么线性卷积后，第0个点对应的时刻是 t_start - (Ns-1) * Ts，因此卷积后的结果应该是要从Ns - 1： Ns - 1 + Nr - 1，这一点你务必要注意

此外线性卷积你需要补零到Ns + Nw - 1，并取Ns - 1： Ns - 1 + Nr - 1这些范围的点。

还要注意单元格实际大小，物理分辨率的关系，雷达真实的分辨率是c / 2B，但是由于过采样每个单元格实际的格子是c / 2fs，对于速度如果你发射了Nc个chirp，但是补零到Nd，你就会发现，分辨率其实还是 lambda / 2 Nc Tr，但是每个格子的大小变成了 lambda / 2 Nd Tr，这一点你也要注意，区分delta r，r bin，delta v， v bin的区别，但是我们一般都会取Nc = Nd = 2的幂，但是我希望你计算时还要分开算。

规定远离速度为正，因此fd = -2vr / lambda，这也就说明，你的频率轴是 （-Nd / 2： Nd / 2 - 1） / Nd * fs，但是最终映射到速度轴还要再乘以 - lambda / 2。
